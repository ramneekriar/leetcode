<h2><a href="https://leetcode.com/problems/implement-trie-prefix-tree/description/">208. Implement Trie (Prefix Tree)</a></h2><h3>Medium</h3>

<p>First, we will create a separate class called TrieNode, which is going to be each individual node of the tree. Each node will have its own set of children as a dictionary and a boolean value indicating whether this node is the end of a word. Each node's children dictionary will be populated at most with 26 letters, with the key being the letter value and the item being that specific TrieNode. In the Trie class, set the root variable to an empty TrieNode. In the insert function, a pointer cur will be pointing towards the root. For every letter in the given string, if it does not exist add the char as key to the current node's dictionary and store a TrieNode at that place. Increment the cur pointer to the TrieNode at current node's char found in its children. Once the word is inserted, for the very last TrieNode, change its isWord boolean value to be True. Very similar logic for searching if a word exists and whether a word starts with a given prefix.</p>
