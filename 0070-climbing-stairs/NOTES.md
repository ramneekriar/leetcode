<h2><a href="https://leetcode.com/problems/climbing-stairs/description/">70. Climbing Stairs</a></h2><h3>Easy</h3>

<p>Until 3 stairs incluisive, there are n ways to climb them. If n = 1, you can only climb 1 stair. If n = 2, you can either climb 1 + 1 stairs, or simply just 2 stairs. If n = 3, then you can climb 1 + 1 + 1 stairs, 1 + 2 stairs or 2 + 1 stairs. These are our base cases covered. After that, let's initialize two variables. Prev1 is equal to 3 because it includes all the different ways to get to the number stairs previously. Prev2 is equal to 2 because it includes all the different ways to get to the number stairs previously to Prev1. Cur is set to 0 because it will hold the sum of all the different ways to reach the nth stair. In the range from 3 (the 4th element) to n, we store the sum of Prev1 and Prev2 in cur. This works because it includes all the combinations to get to the previous 2 stairs for n, and since you can only get to the current stair from these 2 (either climb 1 or 2 stairs). Then we set Prev2 to be the current value of Prev1, and Prev1 to be the value of cur. After the for loop exits, so we have calculated how many ways to reach our nth stair, simply return cur.</p>
