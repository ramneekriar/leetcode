<h2><a href="https://leetcode.com/problems/find-the-number-of-distinct-colors-among-the-balls/description/">3159. Find Occurrences of an Element in an Array</a></h2><h3>Medium</h3>

<p>Create an empty list called positions which will store all the indices of x of where it occurs in nums. Create an empty list answer to store the result. Create a variable num_occurrences to count the number of occurrences. Loop over nums using enumerate to get the index and num. If the num is equal to x, store the index that it occurs at into position. At the same time, increment num_occurrences. Now we have the total number of occurrences of x and all the indices of where it occurs. Loop over the queries. If the ith occurrence it is asking us is larger than num_occurrences, append -1 into our answer list. Otherwise, index into positions with (query - 1) since we are looking for that ith occurrence and our position list is built that way and is also 0-indexed and append that into answer. After, return answer.</p>
