<h2><a href="https://leetcode.com/problems/insert-interval/description/">56. Insert Interval</a></h2><h3>Medium</h3>

<p>We are given an array of non-overlapping intervals where intervals[i] = [start, end]. It is also sorted in ascending order by start. We need to insert newInterval into intervals such that intervals does not have any overlapping intervals. We can return a new array.</p>

<p>Create an empty array called res. Enumerate over index and (start, end). Even though there are many cases, we can do 3 simple checks. First, we will check whether our newInterval comes before the current interval that we are at. We do this by checking whether newInterval[1] (so it's end) is smaller than the current interval's start, if so we append newInterval into res and simply return res + intervals[i:]. Then, we check if our newInterval comes after the current interval. We do this by checking if newInterval[0] (so it's start) is greater than the current interval's end. If so, append the current interval that we are at into res. This is because the newInterval could potentially be merged later. Our last case is when the newInterval overlaps with the current interval. We basically replace newInterval with this, taking the min between newInterval's start and current interval start, and the max between newInterval's end and current interval end, hence merging the two together. After the for loop exits, which means that an early return did not happen, we need to insert whatever value we have in newInterval. Then, return res.</p>
