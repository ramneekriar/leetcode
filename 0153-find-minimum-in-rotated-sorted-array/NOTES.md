<h2><a href="https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/">153. Find Minimum in Rotated Sorted Array</a></h2><h3>Medium</h3>

<p>Set your left and right pointers to 0 and the last index of the array. We already know that in the given array there are unique elements, and that they are all sorted. So let's check if the number at the beginning of the array is smaller than the very last element. If so, then that means the minimum has been found and you can return this number. Otherwise, create a while loop that runs as long as left is smaller or equal to our right index. Calculate the mid point. If the number found at our mid point is smaller than the number at our right pointer, it means that the numbers after index mid are growing towards the right. So we don't have to look at that half anymore and focus on the left half, and set our right pointer to be equal to mid. Else, we set our left pointer to be (mid + 1). This is because the value found at our mid point is bigger than the number at right, which means that there after the mid point, at some point the array will start over again and we want to search the right portion of our array. This is why we just shift the left pointer rightwards as the value of mid has already been compared. In the other comparison, we did not find whether mid itself is the index where the minimum is. After the while loop exists, simply return the number found at the midpoint.</p>
