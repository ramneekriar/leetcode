<h2><a href="https://leetcode.com/problems/valid-palindrome/description/">125. Valid Palindrome</a></h2><h3>Easy</h3>

<h3>Using the Python isalnum() Function</h3>
<p>Initialize pointers left and right as indices to both ends of the given string. While left is smaller or equal to the right pointer, we want to check that the left pointer is smaller than the length of the given string and if the char found at that index is not alphanumeric, we increment the left pointer by 1. Use the same idea for the right pointer and check that the right pointer is bigger than -1, and decrement the right pointer if it is not alphanumeric. Once we've exited out of both of these while loops, we check the boundaries of these pointers once more and check that whether in lowercase these letters do not equal each other. If that is the case, we return False as the given string is not a palindrome. Outside of the if, we can just increment the left and decrement the right pointer. At the end of the whole while loop, we can return True.</p>

While left is smaller or equal to the right pointer, we want to check that the left pointer is smaller than the length of the given string and if the char found at that index is not alphanumeric (check that it does not exist in lowercase between the inclusive range of 97 and 122, and the numerical inclusive range of 47 to 58), we increment the pointer by 1. Use the same idea for the right pointer and check that the right pointer is bigger than -1, and decrement the right pointer if it is not alphanumeric. Once we've exited out of both of these while loops, we check the boundaries of these pointers once more and check that whether in lowercase these letters do not equal each other. If that is the case, we return False as the given string is not a palindrome. Outside of the if, we can just increment the left and decrement the right pointer. At the end of the whole while loop, we can return True.</p>
