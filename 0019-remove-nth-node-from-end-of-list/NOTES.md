<h2><a href="https://leetcode.com/problems/remove-nth-node-from-end-of-list/description/">19. Remove Nth Node From End Of List</a></h2><h3>Medium</h3>

<p>We've been told that head will always have at least one node, and that n is also in the range between 1 and the length of the linked list, which is why we don't have many edge cases to check for. First, create a dummy node and point it to the head of the given linked list. Set our slow and fast pointer to the dummy node as well. We need move the fast pointer n times, to create a distance of n between the slow and fast pointer. After, while fast.next exists, we will move both the slow and fast pointer. This is because, once the fast pointer reaches the last node and cannot be incremented, slow will be pointing to the node just before the nth node. This is how the gap of n is maintained between slow and fast and the node needed to be removed is found. After, just set slow.next = slow.next.next which will work because fast is ahead of this and we know it exists. Then return dummy.next as it was always pointing to the front of the linked list.</p>
