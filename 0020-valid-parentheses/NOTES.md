<h2><a href="https://leetcode.com/problems/valid-parentheses/description/">20. Valid Parentheses</a></h2><h3>Easy</h3>

<p>Create a dictionary holding the close brackets as keys and their open brackets as the values. Name this dictionary close_to_open. Create an empty stack. This stack will hold all the open brackets we encounter in our string. Iterate over each bracket in the given string. If the string does not exist in close_to_open, this means it is an open bracket, so append it to the stack. Otherwise, this means it does exist in close_to_open, so check that our stack exists and that the topmost element of the stack is equal to the bracket found at the close_to_open[bracket]. If so, pop off the topmost element off the stack. If not, this means there is a mismatch between the opening and closing parentheses and it is not in order, so return False. Once this for loop exists, check that stack is empty and that it does not hold any more open parentheses that have not been accounted for. We can do this in a one liner by returning True if not stack else False, or we can also do this by returning if stack == [].</p>
