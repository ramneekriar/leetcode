<h2><a href="https://leetcode.com/problems/house-robber/description/">198. House Robber</a></h2><h3>Medium</h3>

<p>This is a problem asking for the max/min of something and wants us to explore all possibilities. This is hinting at a dp problem. We can do this with top down memoization. So create a dictionary which will serve as a cache so that we avoid doing repeated work. Create an inner function called dp which will work with indices in our nums array. If the index that is passed in is larger or equal to the length of the array, then return 0. If the result is already stored in our cache, then result cache[i]. The logic of this problem is that we cannot rob adjacent houses. So, if we are taking the money at this current house, will store nums[i] + dp(i + 2) in a variable take. This will explore all pathways that stem from taking the money at this house. If we are skipping this house, then we will store dp(i + 1) in variable skip. This will explore all pathways that stem from skipping this house. The result variable will be the max between skip and take. Then we will store result into cache[i] and return result. Outside of the inner function, we simply return dp(0).</p>

<p>How this works: All the pathways of skipping and taking at a certain index will be explored until no more pathways exist, or until no more houses exist in our array, such that index is now out of bounds. Then we will work back up our recursion stack. Between the local take and skip, it will return the max amount of money and store it in the cache at that index and return this value. This will propogate upwards until i=0 basically, and because we populate cache as we work through the recursion upwards, instead of doing the computation again for a different pathway, it will just take the max sum we have already calculated at that index.</p>
