<h2><a href="https://leetcode.com/problems/top-k-frequent-elements/description/">347. Top K Frequent Elements</a></h2><h3>Medium</h3>

<p>Create a hashmap called count which will map the value to the frequency that it appears in nums. Then create freq and initialize it with len(nums) + 1 empty lists.This is because each index will hold the most frequent elements that occur that many times. We give it an extra empty list to make it easier when accessing it by index since python lists are 0-indexed. Iterate over nums and add the freq to the hashmap. For the items in our count hashmap, append that element to the list that occurs at the freq in our freq list. Then initalize an empty list res. Iterate backwards over freq, and for each element in that specific freq list, append it to res and check each time if the len of res is equal to k. If it is, return res.</p>
