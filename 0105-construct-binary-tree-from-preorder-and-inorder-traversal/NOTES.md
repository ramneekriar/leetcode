<h2><a href="https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/">105. Construct a Binary Tree from Preorder and Inorder Traversal</a></h2><h3>Medium</h3>

<p>We are given the preorder and inorder traversal of a binary tree, and have no idea how the actual binary tree looks like. The key is to remember the order of a preorder and inorder traversal. Preorder is root -> left -> right while inorder is left -> root -> right. We can use this exact property to solve this question. In our init method, initialize two variables: preOrderIndex and inOrderHashmap. This is using the property that in preOrderIndex the root node is always stored first, and we are going to be storing the value:index in the inOrderHashmap.</p>

<p>In the parent method buildTree, first we will enumerate over inorder and store the value to index into the inorder hashmap that was initialized. Then, we will call upon our child method buildSubTree and pass in preorder, 0 for our left pointer, and the last index of inorder as our right pointer. This is so we are always going to be looking at either the left or right side of our root when building our subtrees from our inorder traversal list.</p>

<p>In our buildSubTree method, we will first check the base case of whether the left index is bigger than the right, if so return None. Then, grab the rootValue from the preorder list with self.preOrderIndex. Create a TreeNode using that value. Increment self.preOrderIndex. Grab the inOrderIndex from our hashmap using rootValue as the key. This is essentially where the root is located in the inorder traversal. Everything from the left of this is in its left subtree, and vice versa for the right. Then in root.left, recurse over the left side passing in left as left, but right as (inorder - 1). In root.right, recurse over the right side passing in left as (inorder + 1), and right as right. Recursion works so that the entire left side of the main tree will be created first, then it will work back up, then work on creating the entire right branch from parent. At the end, return root.</p>
