<h2><a href="https://leetcode.com/problems/search-in-rotated-sorted-array/">33. Search in Rotated Sorted Array</a></h2><h3>Medium</h3>

<p>Initalize your left and right pointers as indices to both ends of the given array. While our left pointer is less than or equal to our right pointer we execute the following code. Calculate the midpoint. If the number at our midpoint is equal to the target we are searching for, simply return the midpoint. If the number at midpoint happens to greater or equal to our number at the left index, this means that everything from our left pointer to the mid pointer is increasing and is sorted. So we enter this if clause. If the target is bigger than the number at midpoint, we can disregard everything from left pointer to the mid pointer (inclusive) (since we already know it is sorted) and move left to be (mid + 1). If this is not the case, it means target must be smaller than the number at the midpoint. In this else block, first check if target is smaller than the number at our left pointer, if so we can move left to be (mid + 1). We can do this because we entered the larger if block knowing that everything from left to midpoint was increasing and in order, so the number will be found in the right sorted portion of the array. Else, we can move right to be (mid - 1). If the number at midpoint is less than the number at the left index (from the main if block), we enter into an else condition where we are now checking the right sorted portion of the array. If target is smaller than the number at midpoint, then we can move right to be (mid - 1). Else, we will enter into another if-else block. Check if target is bigger than the number at midpoint, if so then we move right to (mid - 1). (This is because from the larger else block, nums[mid] is smaller than the nums[left], meaning that the left half of the array contains larger numbers.) Else, we can move left to be (mid + 1). This entire while loop will keep running until at some point our target is found. If that is not the case and the left and right pointers overlap, simply return -1.</p>
