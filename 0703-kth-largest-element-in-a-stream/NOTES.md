<h2><a href="https://leetcode.com/problems/kth-largest-element-in-a-stream/description/">703. Kth Largest Element in a Stream</a></h2><h3>Easy</h3>

<p>We will be using a heap data structure for this problem, so import heapq. In our init method, we need to have a self.k to always keep track of what kth largest we are storing, and self.heap which will be set to nums. Using heapq.heapify, we will heapify our self.heap. The default heap data structure in Python is a minHeap, so the smallest value in the heap will be at the root of the heap/top of the heap, while the largest value will be at the bottom. After heapifying, while the length of our heap is larger than the k we are provided with, heappop. We only need to keep track of k values at a time within the stream, not every element. Then in the add method, push on the value being added to the heap. If this increases the length of our heap and it is larger than self.k, then heappop to remove the most smallest element in our heap so far. Then return self.heap[0] since the element in the very bottom of our minHeap is the largest kth element we have seen so far. This is becase again, we are only maintaining k elements at a time in our heap.</p>
