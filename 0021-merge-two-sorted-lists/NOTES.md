<h2><a href="https://leetcode.com/problems/merge-two-sorted-lists/description/">21. Merge Two Sorted Lists</a></h2><h3>Easy</h3>

<h3>Recursive Approach</h3>
<p>In the recursive approach, we do not require any extra memory as we are sorting the linked lists in place. First, check if list1 exists, if not then return list2 as is. Check if list2 exists, if not then return list1 as is. Then check if the value of the node at list1 is smaller than the value of the node at list2. If so, then the next value of list1 will hold the result of recursively calling the sort function but this time we increase our list1 pointer (list1.next) and keep list2 as is. Then return list1. Otherwise, the value of list2 must be smaller or equal than list1, so do the same thing with the next value of list2 recursively calling the sort function, this time passing in list1 as is and list2.next. Then return list2. At some point, either list1 or list2 will be empty and this will hit the base case where our final sorted linked list will be returned.</p>

<h3>Iterative Approach</h3>
<p>In the iterative approach, we will be creating a brand new linked list to return at the end. Create a pointer called dummy and node which both point to a brand new ListNode object. The pointer dummy is used so we have a reference always to the front of the linked list and can return dummy.next at the end from where the actual sorted linked list starts. While both list1 and list2 exist and have nodes, check if list1.val is smaller than the value of list2.val, if it is then point node.next to list1 and increment our list1 pointer. Vice versa for list2, the value at list2 must be equal or smaller so point node.next to list2 and increment our list2 pointer. Outside of the if-else statement, we increment our node pointer to the point to the new node that was just added. Once the while loop exits, it means either list1 or list2 is empty. Therefore, point node.next to whichever list exists by doing node.next = list1 or list2. Then we can simply return the linked list starting from dummy.next as dummy is simply an empty node/ptr to keep reference to the front of the linked list.</p>
