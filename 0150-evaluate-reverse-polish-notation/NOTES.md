<h2><a href="https://leetcode.com/problems/evaluate-reverse-polish-notation/description/">150. Evaluate Reverse Polish Notation</a></h2><h3>Medium</h3>

<p>Create an empty stack. Iterate through each token, we will have conditions to check if it equals an operand, otherwise the default will be to append the token to the stack as an integer since we want to be able to perform calculations with it. If token is +, then append the sum of the two topmost elements of the stack. If it is -, then append the subtraction of the two topmost elements of the stack (temp2 - temp1). If the token is *, then append the product of the two topmost elements of the stack. If the token is /, then append the division of the two topmost elements of the stack (temp2 / temp1). We then use int around this to truncate towards 0. We can't use integer division as that truncates towards the smaller number, meaning in the negative case (-5//2) would be -3 instead of -2 as expected in this problem.</p>
