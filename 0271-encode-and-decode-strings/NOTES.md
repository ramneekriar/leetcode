<h2><a href="https://neetcode.io/problems/string-encode-and-decode">271. Encode and Decode Strings</a></h2><h3>Medium</h3>

<p>In the Encode method, create an empty string. Iterate over the given list of words and append first the length, a delimiter character, then the actual word. For example, the word list ["neet", "code"] will look like "4#neet4#code". Return this string. In the Decode method, create an empty list. Set i to index 0 and start a while loop until i is smaller than length of the given string. Inside this while loop, have another variable j be pointing to where i is. While the character at index j does not equal our delimiter character, increment j. Once it does, it means according to our set up, the length of the current word in the string is stored between i and j. Extract that. Then the actual word must be from index (j + 1) until j + length + 1 (as the end index is not inclusive in Python). Append the word to the list. Point our i pointer to j + length + 1 to begin this process for the next word. Return the list.</p>
