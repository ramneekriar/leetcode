<h2><a href="https://leetcode.com/problems/linked-list-cycle/">143. Reorder List</a></h2><h3>Medium</h3>

<p>First, we do the classic slow and fast pointer to find the middle of the list. Basically, we need to reverse the second half of the list and use that to be inserted in the first list in alternating order. So once the pointer iteration is complete, our slow pointer will point to the middle of the linked list. Everything after slow will need to be reversed. So, create a pointer called second which will point to slow.next. Then, change slow.next to None so that the first half of the list has an ending point. Example: head = 1 -> 2 -> 3 -> None, second = 4 -> 5 -> None. Create a pointer called node and set it to None. We will build our reversed list here. While second exists, do the following. In a temp variable, hold second.next (5 -> None) since we will need to iterate over this after. Change second.next to be equal to node (4 -> None). Set node to be second (4 -> None). Set second to be temp so our iteration can continue. This will repeat and this time second.next will be set to everything we've built in node so far (so 5 -> 4 -> None). The loop will eventually end once the list is reversed. Now to move on to inserting the second reversed half into the first in alternating order. Set first to head, and set second to node. While second exists, hold first.next in temp1 (2 -> ...) and second.next (4 -> None) in temp2. Inline, switch first.next to be second (1 -> 5...), and second.next to be temp1 (1 -> 5 -> 2 -> ...). Inline, set first to be temp1 (2 -> ...) and second to be temp2 (4 -> None) for our next iteration. Eventually, the list will be reordered as needed. Yeah, this one takes a while to understand the whole pointers thing ://</p>
