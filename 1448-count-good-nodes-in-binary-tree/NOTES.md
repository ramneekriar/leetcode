<h2><a href="https://leetcode.com/problems/count-good-nodes-in-binary-tree/">1448. Count Good Nodes in Binary Tree</a></h2><h3>Medium</h3>

<p>This is a depth-first-search problem as we need to traverse the tree downwards to find all good nodes. A good node is such that from the root node until that node, no value is greater than node.val. We will always be given a tree with at least one node. In that case, first we check for that case. If the tree only has a root node, simply return 1. Now we can start a dfs function. We will have 2 parameters: root and the max_so_far, the max value encountered in the path so far as we search. Initialize a count variable to 0. This variable will be our accumulator to count all the good nodes. If root is None, then return 0. If our current root value happens to be bigger or equal to the max_so_far, then increment count. Then run the dfs on the left subtree and right subtree, making sure to pass in the max value between the current root value and the prev max_so_far so it is updated accordingly. The results will be added into count like this: count += dfs(root.left, max(root.val, max_so_far)). Then at the end return count. What's happening is that the recursion will go on until there are no more subtrees to traverse, so that the count will be incremented and propogated upwards in the recursion stack. This works because in that local function domain, count has been incremented and the results from function calls thereafter have been returned. This will keep building up. To call this depth first function then, we simply return the value from dfs(root, root.val).</p>
