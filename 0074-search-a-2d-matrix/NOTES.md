<h2><a href="https://leetcode.com/problems/search-a-2d-matrix/description/">74. Search a 2D Matrix</a></h2><h3>Medium</h3>

<p>To complete this in O(log(m*n)), we are essentially going to be performing binary search twice: first to find the correct row to search in, and then to search within that row to the find the target element we are looking for. Initialize rows and cols variable to be the length of the matrix and the length of each row. Initialize top to be 0 and bot to be (rows - 1). These will be our pointers to search for the exact row we need. While top is smaller or equal to bot, calculate the midrow we will be searching. If the first element of this row happens to be bigger than our target, then set the bottom row to be (row - 1) since we need to search before this current row. If the last element of this row happens to be smaller than our target, then set the top row to be (row + 1) since we need to serach after this current row. If this is neither the case, we break out of this loop. This means we've found the appropriate row to search in. We check to make sure that a valid row has been found by checking that top is still less than or equal to bot. If not, then return False. Then calculate the row we are searching in. Initialize our left and right pointer for that row. Perform binary search as normal on this row to find our target value.</p>
