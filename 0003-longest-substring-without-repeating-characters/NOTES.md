<h2><a href="https://leetcode.com/problems/longest-substring-without-repeating-characters/description/">3. Longest Substring Without Repeating Characters</a></h2><h3>Medium</h3>

<p>We use the sliding window approach to find out the longest substring without repeating characters. For this, we will use a set to store the unique characters we have seen so far. First, check if we are given an empty string and return 0 if so. Initialize a left and right pointer to 0, a result variable, and a set called seen. While our right pointer is smaller than the length of the list, check if the character at our right pointer already exists in our set so far. While it does, we need to remove the character at the left index and increase our left pointer. At one point, when the character at the right pointer is no longer in our set the while loop will exit. Here, we can add the character at the right pointer to the set. Calculate the max length of a substring we have seen so far by comparing what we have in res and (right - left + 1). Increase the right pointer to visit the next character. At the end of the overal while loop, return res.</p>
