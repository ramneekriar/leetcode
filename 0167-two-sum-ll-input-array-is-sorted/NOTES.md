<h2><a href="https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/description/">167. Two Sum II - Input Array Is Sorted</a></h2><h3>Medium</h3>

<p>The array given to us is already in sorted, ascending order. They said that it is going to be 1-indexed, but in Python we know that list structures are 0-indexed. So this means that when we return our answer, we must add 1 to each index where the two numbers are found such that they add up to target. Initialize two pointers left and right and point them to their respective indices, each end of the list. While left is smaller than right, calculate the total from the numbers found at index left and right. If this equals to target, return the indices as a list and add 1 to each. If our total happens to be bigger than our target, this means we can decrement our right pointer and find a smaller number to work with. Otherwise, our total is smaller than our target, so we can increment our left pointer and find a bigger number to work with. Again, we can do this because we take advantage of the fact that our list is sorted. This problem is guaranteed to have a solution, so at some point total will equal to target and the function will return a list.</p>
