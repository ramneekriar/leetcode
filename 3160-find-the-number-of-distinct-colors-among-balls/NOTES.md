<h2><a href="https://leetcode.com/problems/find-the-number-of-distinct-colors-among-the-balls/description/">3160. Find the Number of Distinct Colors Among Balls</a></h2><h3>Medium</h3>

<p>Create a default int dictionary for ball_to_color and color_freq. Create a result list. This will map the ball to the color that it will be assigned and color_freq will hold the freq of each color that we have. Loop over the queries, extracting the ball and color value. First, get the prev_color by doing ball_to_color[ball]. Then we want to check if this value is greater than 0, which means that the ball had a previous color assigned to it. In that case, we decrement color_freq at that color and then we want to check if after decremenging the freq goes to 0. If that's the case, we want to delete this key from color_freq. This it to make it easier when we append the number of distinct colors into out result list. After doing these checks, update the color of ball in ball_to_color and update the freq of color in color_freq[color]. Then, append the length of color_freq into result, which is the distinct colors that exist so far. After the for loop exits, return result.</p>
