<h2><a href="https://leetcode.com/problems/binary-search/description/">704. Binary Search</a></h2><h3>Easy</h3>

<h3>Iterative</h3>
<p>Create a left and right pointer and point them towards their respective ends of the given list. Create a while loop that keeps running as long as our left pointer is smaller or equal to our right pointer. Calculate the mid point. If the number at index mid is the target we are searching for, then we can simply return mid. If the number at mid is bigger than target, then we move the right pointer to index (mid - 1), since we can disregard the rest of the list and our value will for sure will not be found there. On the other hand if the number is smaller than target, then increase the left pointer to (mid + 1), since we can disregard the rest of the list on the left hand side as our value for sure will not be found there. If the while loop exits without returning the index where target exists, we can return -1 as target has not been found.</p>

<h3>Recursive</h3>
<p>Create a another function definition and this will have the given list, a left pointer, a right pointer and our target. Our main function will call and return this function by passing in the given list, left pointer set to 0, the right pointer set to the last index of the list, and the given target value. Inside our recursive function: If our left pointer is bigger than our right, we can return -1. Calculate the mid point. If the value at the midpoint is the target, return the midpoint. If the number at mid is bigger than our target, then call the recursive function, this time passing in (mid - 1) as our right value and the other values stay the same. If the number at mid is smaller than our target, then call the recursive function, this time passing in (mid + 1) as our left value and the other values stay the same.</p>
